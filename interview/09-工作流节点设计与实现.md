## 一、节点架构概览

### 1.1 节点分类体系

Dify 工作流节点按功能和执行方式分为以下几类：

| 分类 | 节点类型 | 说明 |
|------|---------|------|
| **入口/出口** | START, END | 工作流入口和出口 |
| **AI 模型** | LLM, Agent | 大模型调用、智能体 |
| **数据处理** | Code, Template Transform | 代码执行、模板转换 |
| **外部交互** | HTTP Request, Tool | HTTP 请求、工具调用 |
| **知识库** | Knowledge Retrieval, Document Extractor | 知识检索、文档提取 |
| **流程控制** | IF-ELSE, Question Classifier | 条件分支、问题分类 |
| **循环迭代** | Iteration, Loop | 迭代、循环 |
| **变量操作** | Variable Assigner, Variable Aggregator | 变量赋值、聚合 |
| **输出节点** | Answer, Human Input | 答案输出、人工输入 |

### 1.2 节点执行类型

```python
class NodeExecutionType(StrEnum):
    """节点执行类型"""
    EXECUTABLE = "executable"  # 可执行节点（大多数节点）
    BRANCH = "branch"          # 分支节点（IF-ELSE）
    CONTAINER = "container"    # 容器节点（Iteration, Loop）
    RESPONSE = "response"      # 响应节点（Answer）
    ROOT = "root"              # 根节点（START）
```

## 二、节点基类设计

### 2.1 Node 基类

所有节点都继承自 `Node` 基类。

**代码位置**: `api/core/workflow/nodes/base/node.py`

```python
class Node:
    """节点基类"""
    
    # 类变量
    node_type: ClassVar["NodeType"]  # 节点类型（子类必须定义）
    execution_type: NodeExecutionType = NodeExecutionType.EXECUTABLE
    
    def __init__(
        self,
        id: str,  # 节点实例 ID
        config: Mapping[str, Any],  # 节点配置
        graph_init_params: "GraphInitParams",  # 图初始化参数
        graph_runtime_state: "GraphRuntimeState",  # 运行时状态
    ) -> None:
        # 基本属性
        self.id = id
        self.tenant_id = graph_init_params.tenant_id
        self.app_id = graph_init_params.app_id
        self.workflow_id = graph_init_params.workflow_id
        self.user_id = graph_init_params.user_id
        self.graph_config = graph_init_params.graph_config
        self.graph_runtime_state = graph_runtime_state
        
        # 节点状态
        self.state: NodeState = NodeState.UNKNOWN
        
        # 节点配置 ID
        self._node_id = config.get("id")
        self._node_execution_id: str = ""
        self._start_at = naive_utc_now()
    
    @abstractmethod
    def init_node_data(self, data: Mapping[str, Any]) -> None:
        """初始化节点数据（子类实现）"""
        ...
    
    @abstractmethod
    def _run(self) -> NodeRunResult | Generator[NodeEventBase, None, None]:
        """运行节点（子类实现）"""
        raise NotImplementedError
    
    def run(self) -> Generator[GraphNodeEventBase, None, None]:
        """
        运行节点（公共方法）
        
        流程：
        1. 生成节点执行 ID
        2. 发射 NodeRunStartedEvent
        3. 执行节点逻辑（_run）
        4. 处理结果（阻塞 or 流式）
        5. 发射完成事件
        """
        # 1. 生成执行 ID
        if not self._node_execution_id:
            self._node_execution_id = str(uuid4())
        self._start_at = naive_utc_now()
        
        # 2. 发射启动事件
        start_event = NodeRunStartedEvent(
            id=self._node_execution_id,
            node_id=self._node_id,
            node_type=self.node_type,
            node_title=self.title,
            start_at=self._start_at,
        )
        yield start_event
        
        try:
            # 3. 执行节点逻辑
            result = self._run()
            
            # 4. 处理结果
            if isinstance(result, NodeRunResult):
                # 阻塞模式：直接返回结果
                yield self._convert_node_run_result_to_graph_node_event(result)
            else:
                # 流式模式：逐个处理事件
                for event in result:
                    # 转换为 GraphNodeEvent
                    graph_event = self._convert_to_graph_event(event)
                    yield graph_event
        
        except Exception as e:
            # 发射失败事件
            failed_event = self._create_failed_event(e)
            yield failed_event
```

**设计要点**：

1. **抽象方法**：`init_node_data` 和 `_run` 必须由子类实现
2. **事件生成**：`run` 方法统一处理事件流
3. **两种返回模式**：
   - 阻塞模式：返回 `NodeRunResult`
   - 流式模式：返回 `Generator[NodeEventBase]`

### 3.3 核心实现

```python
class LLMNode(Node):
    node_type = NodeType.LLM
    
    def _run(self) -> Generator[NodeEventBase, None, None]:
        """执行 LLM 节点"""
        
        # 1. 获取模型实例
        model_instance = ModelManager().get_model_instance(
            tenant_id=self.tenant_id,
            provider=self._node_data.model.provider,
            model_type=ModelType.LLM,
            model=self._node_data.model.name,
        )
        
        # 2. 构建 Prompt 消息
        prompt_messages = self._build_prompt_messages()
        
        # 3. 处理 Memory（如果配置）
        if self._node_data.memory:
            memory = self._fetch_memory()
            history_messages = memory.get_history_prompt_messages()
            prompt_messages = history_messages + prompt_messages
        
        # 4. 准备模型参数
        model_parameters = self._prepare_model_parameters()
        
        # 5. 调用模型
        if self._node_data.structured_output:
            # 结构化输出模式
            result = invoke_llm_with_structured_output(
                model_instance=model_instance,
                prompt_messages=prompt_messages,
                model_parameters=model_parameters,
                structured_output_schema=self._node_data.structured_output.schema,
            )
        else:
            # 普通模式
            result = model_instance.invoke(
                model=self._node_data.model.name,
                prompt_messages=prompt_messages,
                model_parameters=model_parameters,
                stream=True,  # 流式输出
                user=self.user_id,
            )
        
        # 6. 处理流式输出
        file_outputs: list[File] = []
        file_saver = LLMFileSaver(tenant_id=self.tenant_id, user_id=self.user_id)
        
        yield from self.handle_invoke_result(
            invoke_result=result,
            file_saver=file_saver,
            file_outputs=file_outputs,
            node_id=self._node_id,
            node_type=self.node_type,
        )
    
    @staticmethod
    def handle_invoke_result(
        *,
        invoke_result: LLMResult | Generator[LLMResultChunk, None, None],
        file_saver: LLMFileSaver,
        file_outputs: list[File],
        node_id: str,
        node_type: NodeType,
    ) -> Generator[NodeEventBase, None, None]:
        """
        处理 LLM 调用结果
        
        特性：
        - 支持流式输出
        - 处理多模态内容（图片、音频）
        - 计算 Token 使用量
        - 计算 TTFT（首 Token 时间）
        """
        full_text_buffer = io.StringIO()
        usage = LLMUsage.empty_usage()
        finish_reason = None
        has_content = False
        first_token_time = None
        request_start_time = time.perf_counter()
        
        # 流式处理
        for result in invoke_result:
            if isinstance(result, LLMResultChunk):
                contents = result.delta.message.content
                
                # 处理多模态内容
                for text_part in LLMNode._save_multimodal_output_and_convert_result_to_markdown(
                    contents=contents,
                    file_saver=file_saver,
                    file_outputs=file_outputs,
                ):
                    # 检测首 Token
                    if text_part and not has_content:
                        first_token_time = time.perf_counter()
                        has_content = True
                    
                    # 写入缓冲区
                    full_text_buffer.write(text_part)
                    
                    # 发射文本 chunk 事件
                    yield StreamChunkEvent(
                        selector=[node_id, "text"],
                        chunk=text_part,
                        is_final=False,
                    )
                
                # 更新元数据
                if result.delta.usage:
                    usage = result.delta.usage
                if result.delta.finish_reason:
                    finish_reason = result.delta.finish_reason
        
        # 计算 TTFT
        ttft = None
        if first_token_time and request_start_time:
            ttft = first_token_time - request_start_time
        
        # 返回最终结果
        full_text = full_text_buffer.getvalue()
        
        yield StreamCompletedEvent(
            node_run_result=NodeRunResult(
                status=WorkflowNodeExecutionStatus.SUCCEEDED,
                outputs={
                    "text": full_text,
                    "usage": usage.model_dump(),
                    "finish_reason": finish_reason,
                },
                llm_usage=usage,
                metadata={
                    "ttft": ttft,
                    "files": [file.to_dict() for file in file_outputs],
                },
            )
        )
```

**设计亮点**：

1. **流式输出**：逐 chunk 发射事件，实时展示
2. **多模态支持**：处理图片、音频等非文本内容
3. **性能指标**：计算 TTFT、Token 使用量
4. **Memory 集成**：自动加载历史对话
5. **结构化输出**：支持 JSON Schema 约束

```python
class AgentNode(Node):
    node_type = NodeType.AGENT
    
    def _run(self) -> Generator[NodeEventBase, None, None]:
        """执行 Agent 节点"""
        
        # 1. 获取 Agent 策略
        strategy = get_plugin_agent_strategy(
            tenant_id=self.tenant_id,
            provider_name=self._node_data.agent_strategy_provider_name,
            strategy_name=self._node_data.agent_strategy_name,
        )
        
        # 2. 准备参数
        parameters = self._generate_agent_parameters(
            agent_parameters=strategy.parameters,
            variable_pool=self.graph_runtime_state.variable_pool,
            node_data=self._node_data,
            strategy=strategy,
        )
        
        # 3. 获取对话 ID
        conversation_id = self.graph_runtime_state.variable_pool.get(
            ["sys", SystemVariableKey.CONVERSATION_ID]
        )
        
        # 4. 调用 Agent
        try:
            message_stream = strategy.invoke(
                params=parameters,
                user_id=self.user_id,
                app_id=self.app_id,
                conversation_id=conversation_id.text if conversation_id else None,
                credentials=credentials,
            )
        except Exception as e:
            yield StreamCompletedEvent(
                node_run_result=NodeRunResult(
                    status=WorkflowNodeExecutionStatus.FAILED,
                    error=f"Failed to invoke agent: {str(e)}",
                )
            )
            return
        
        # 5. 转换消息流
        try:
            yield from self._transform_message(
                messages=message_stream,
                tool_info={
                    "icon": self.agent_strategy_icon,
                    "agent_strategy": self._node_data.agent_strategy_name,
                },
                parameters_for_log=parameters_for_log,
                user_id=self.user_id,
                tenant_id=self.tenant_id,
                node_type=self.node_type,
                node_id=self._node_id,
                node_execution_id=self.id,
            )
        except Exception as e:
            yield StreamCompletedEvent(
                node_run_result=NodeRunResult(
                    status=WorkflowNodeExecutionStatus.FAILED,
                    error=f"Failed to transform agent message: {str(e)}",
                )
            )
```

```python
class CodeNode(Node):
    node_type = NodeType.CODE
    
    def _run(self) -> NodeRunResult:
        """执行代码节点"""
        
        # 1. 获取代码语言和代码
        code_language = self._node_data.code_language
        code = self._node_data.code
        
        # 2. 准备变量
        variables = {}
        for variable_selector in self._node_data.variables:
            variable_name = variable_selector.variable
            variable = self.graph_runtime_state.variable_pool.get(
                variable_selector.value_selector
            )
            
            # 转换为 Python 对象
            if isinstance(variable, ArrayFileSegment):
                variables[variable_name] = [v.to_dict() for v in variable.value]
            else:
                variables[variable_name] = variable.to_object() if variable else None
        
        # 3. 执行代码
        try:
            result = CodeExecutor.execute_workflow_code_template(
                language=code_language,
                code=code,
                inputs=variables,
            )
            
            # 4. 验证和转换结果
            result = self._transform_result(
                result=result,
                output_schema=self._node_data.outputs
            )
        
        except (CodeExecutionError, CodeNodeError) as e:
            return NodeRunResult(
                status=WorkflowNodeExecutionStatus.FAILED,
                inputs=variables,
                error=str(e),
                error_type=type(e).__name__,
            )
        
        # 5. 返回成功结果
        return NodeRunResult(
            status=WorkflowNodeExecutionStatus.SUCCEEDED,
            inputs=variables,
            outputs=result,
        )
```

```python
class CodeExecutor:
    """代码执行器"""
    
    @staticmethod
    def execute_workflow_code_template(
        language: CodeLanguage,
        code: str,
        inputs: dict[str, Any],
    ) -> dict[str, Any]:
        """
        执行工作流代码模板

        - 沙箱环境执行
        - 限制执行时间
        - 限制内存使用
        - 限制网络访问

        if language == CodeLanguage.PYTHON3:

            raise ValueError(f"Unsupported language: {language}")
```

```python
class HttpRequestNode(Node):
    node_type = NodeType.HTTP_REQUEST
    
    def _run(self) -> NodeRunResult:
        """执行 HTTP 请求节点"""
        
        # 1. 创建执行器
        executor = Executor(
            node_data=self._node_data,
            timeout=self._node_data.timeout or HTTP_REQUEST_DEFAULT_TIMEOUT,
            variable_pool=self.graph_runtime_state.variable_pool,
        )
        
        # 2. 执行请求
        try:
            response = executor.invoke()
        except HttpRequestNodeError as e:
            return NodeRunResult(
                status=WorkflowNodeExecutionStatus.FAILED,
                error=str(e),
                error_type=type(e).__name__,
            )
        
        # 3. 处理响应
        outputs = {
            "status_code": response.status_code,
            "headers": dict(response.headers),
            "body": response.text if not response.is_file else None,
            "files": [response.file.to_dict()] if response.is_file else None,
        }
        
        return NodeRunResult(
            status=WorkflowNodeExecutionStatus.SUCCEEDED,
            outputs=outputs,
        )
```

**执行器实现**：

```python
class Executor:
    """HTTP 请求执行器"""
    
    def invoke(self) -> Response:
        """执行 HTTP 请求"""
        
        # 1. 初始化（URL、参数、Headers、Body）
        self._initialize()
        
        # 2. 组装 Headers
        headers = self._assembling_headers()
        
        # 3. 执行请求
        response = self._do_http_request(headers)
        
        # 4. 验证和解析响应
        return self._validate_and_parse_response(response)
    
    def _do_http_request(self, headers: dict[str, Any]) -> httpx.Response:
        """执行 HTTP 请求"""
        
        # 使用 SSRF 代理（防止 SSRF 攻击）
        _METHOD_MAP = {
            "get": ssrf_proxy.get,
            "post": ssrf_proxy.post,
            "put": ssrf_proxy.put,
            "patch": ssrf_proxy.patch,
            "delete": ssrf_proxy.delete,
        }
        
        method_lc = self.method.lower()
        if method_lc not in _METHOD_MAP:
            raise InvalidHttpMethodError(f"Invalid http method {self.method}")
        
        # 执行请求
        try:
            response = _METHOD_MAP[method_lc](
                url=self.url,
                data=self.data,
                files=self.files,
                json=self.json,
                headers=headers,
                params=self.params,
                timeout=(self.timeout.connect, self.timeout.read, self.timeout.write),
                ssl_verify=self.ssl_verify,
                follow_redirects=True,
                max_retries=self.max_retries,
            )
        except (ssrf_proxy.MaxRetriesExceededError, httpx.RequestError) as e:
            raise HttpRequestNodeError(str(e)) from e
        
        return response
```

**SSRF 防护**：

Dify 使用 `ssrf_proxy` 包装所有 HTTP 请求，防止 SSRF（服务器端请求伪造）攻击：

```python
class KnowledgeRetrievalNode(Node):
    node_type = NodeType.KNOWLEDGE_RETRIEVAL
    
    def _run(self) -> NodeRunResult:
        """执行知识检索节点"""
        
        # 1. 提取查询文本
        query = self.graph_runtime_state.variable_pool.get(
            self._node_data.query_variable_selector
        )
        
        if not query or not query.text:
            raise ValueError("Query is required")
        
        query_text = query.text
        
        # 2. 执行检索
        try:
            documents, usage = self._fetch_dataset_retriever(
                node_data=self._node_data,
                query=query_text,
            )
        except Exception as e:
            return NodeRunResult(
                status=WorkflowNodeExecutionStatus.FAILED,
                error=str(e),
            )
        
        # 3. 格式化输出
        outputs = {
            "result": documents,  # 检索到的文档列表
            "metadata": {
                "retrieval_method": self._node_data.single_retrieval_config.model.search_method,
                "top_k": len(documents),
            }
        }
        
        return NodeRunResult(
            status=WorkflowNodeExecutionStatus.SUCCEEDED,
            outputs=outputs,
            llm_usage=usage,
        )
    
    def _fetch_dataset_retriever(
        self,
        node_data: KnowledgeRetrievalNodeData,
        query: str,
    ) -> tuple[list[dict[str, Any]], LLMUsage]:
        """
        执行数据集检索
        
        步骤：
        1. 获取可用数据集
        2. 元数据过滤（如果启用）
        3. 执行检索
        4. Rerank（如果启用）
        5. 合并结果
        """
        usage = LLMUsage.empty_usage()
        
        # 1. 获取可用数据集
        available_datasets = []
        dataset_ids = node_data.dataset_ids
        
        # 查询有可用文档的数据集
        results = (
            db.session.query(Dataset)
            .where(
                Dataset.tenant_id == self.tenant_id,
                Dataset.id.in_(dataset_ids),
                Dataset.available_document_count > 0,
            )
            .all()
        )
        
        for dataset in results:
            if dataset:
                available_datasets.append(dataset)
        
        # 2. 元数据过滤
        metadata_filter_document_ids, metadata_condition, metadata_usage = \
            self._get_metadata_filter_condition(
                [dataset.id for dataset in available_datasets],
                query,
                node_data,
            )
        usage = self._merge_usage(usage, metadata_usage)
        
        # 3. 执行检索
        all_documents = []
        dataset_retrieval = DatasetRetrieval()
        
        if node_data.retrieval_mode == "single":
            # 单数据集模式
            for dataset in available_datasets:
                documents = dataset_retrieval.retrieve(
                    dataset=dataset,
                    query=query,
                    top_k=node_data.single_retrieval_config.top_k,
                    score_threshold=node_data.single_retrieval_config.score_threshold,
                    reranking_model=node_data.single_retrieval_config.reranking_model,
                    metadata_filter=metadata_condition,
                )
                all_documents.extend(documents)
        
        else:
            # 多数据集模式
            all_documents = dataset_retrieval.retrieve_multi(
                datasets=available_datasets,
                query=query,
                top_k=node_data.multiple_retrieval_config.top_k,
                score_threshold=node_data.multiple_retrieval_config.score_threshold,
                reranking_model=node_data.multiple_retrieval_config.reranking_model,
                metadata_filter=metadata_condition,
            )
        
        return all_documents, usage
```

```python
    def _run(self) -> NodeRunResult:
```

**条件处理器**：

```python
class ConditionProcessor:
    """条件处理器"""
    
    def process_conditions(
        self,
        *,
        variable_pool: VariablePool,
        conditions: list[Condition],
        operator: Literal["and", "or"],
    ) -> tuple[list[dict], list[dict], bool]:
        """
        处理条件列表
        
        Returns:
            - input_conditions: 输入条件列表
            - group_result: 每个条件的结果
            - final_result: 最终结果（and/or 运算后）
        """
        input_conditions = []
        group_result = []
        
        for condition in conditions:
            # 1. 获取变量值
            variable = variable_pool.get(condition.variable_selector)
            
            # 2. 评估条件
            result = self._evaluate_condition(
                variable=variable,
                operator=condition.comparison_operator,
                value=condition.value,
            )
            
            # 3. 记录结果
            input_conditions.append({
                "variable": condition.variable_selector,
                "operator": condition.comparison_operator,
                "value": condition.value,
            })
            
            group_result.append({
                "condition": condition.model_dump(),
                "result": result,
            })
        
        # 4. 计算最终结果
        if operator == "and":
            final_result = all(r["result"] for r in group_result)
        else:  # or
            final_result = any(r["result"] for r in group_result)
        
        return input_conditions, group_result, final_result
    
    def _evaluate_condition(
        self,
        variable: Variable | None,
        operator: str,
        value: str | None,
    ) -> bool:
        """评估单个条件"""
        
        if operator == "is_empty":
            return variable is None or variable.value in [None, "", []]
        
        if operator == "is_not_empty":
            return variable is not None and variable.value not in [None, "", []]
        
        if variable is None:
            return False
        
        var_value = variable.to_object()
        
        if operator == "is":
            return str(var_value) == value
        
        elif operator == "is_not":
            return str(var_value) != value
        
        elif operator == "contains":
            return value in str(var_value)
        
        elif operator == "not_contains":
            return value not in str(var_value)
        
        elif operator == "starts_with":
            return str(var_value).startswith(value)
        
        elif operator == "ends_with":
            return str(var_value).endswith(value)
        
        elif operator == "greater_than":
            return float(var_value) > float(value)
        
        elif operator == "less_than":
            return float(var_value) < float(value)
        
        elif operator == "greater_than_or_equal":
            return float(var_value) >= float(value)
        
        elif operator == "less_than_or_equal":
            return float(var_value) <= float(value)
        
        return False
```

```python
class IterationNode(Node):
    node_type = NodeType.ITERATION
    execution_type = NodeExecutionType.CONTAINER
    
    def _run(self) -> Generator[NodeEventBase, None, None]:
        """执行迭代节点"""
        
        # 1. 获取迭代器变量
        variable = self._get_iterator_variable()
        
        # 2. 验证并获取列表
        iterator_list_value = self._validate_and_get_iterator_list(variable)
        
        # 3. 初始化
        outputs: list[object] = []
        iter_run_map: dict[str, float] = {}
        usage_accumulator = [LLMUsage.empty_usage()]
        
        # 4. 发射启动事件
        yield IterationStartedEvent(
            start_at=naive_utc_now(),
            inputs={"iterator_selector": iterator_list_value},
            metadata={"iteration_length": len(iterator_list_value)},
        )
        
        # 5. 执行迭代
        try:
            yield from self._execute_iterations(
                iterator_list_value=iterator_list_value,
                outputs=outputs,
                iter_run_map=iter_run_map,
                usage_accumulator=usage_accumulator,
            )
            
            # 6. 处理成功
            yield from self._handle_iteration_success(
                outputs=outputs,
                iter_run_map=iter_run_map,
                usage=usage_accumulator[0],
            )
        
        except IterationNodeError as e:
            # 7. 处理失败
            yield from self._handle_iteration_failure(e)
    
    def _execute_iterations(
        self,
        iterator_list_value: Sequence[object],
        outputs: list[object],
        iter_run_map: dict[str, float],
        usage_accumulator: list[LLMUsage],
    ) -> Generator[NodeEventBase, None, None]:
        """执行迭代"""
        
        if self._node_data.is_parallel:
            # 并行模式
            yield from self._execute_parallel_iterations(
                iterator_list_value=iterator_list_value,
                outputs=outputs,
                iter_run_map=iter_run_map,
                usage_accumulator=usage_accumulator,
            )
        else:
            # 串行模式
            for index, item in enumerate(iterator_list_value):
                iter_start_at = datetime.now(UTC).replace(tzinfo=None)
                
                # 发射迭代事件
                yield IterationNextEvent(index=index)
                
                # 创建子图引擎
                graph_engine = self._create_graph_engine(index, item)
                
                # 运行单次迭代
                yield from self._run_single_iter(
                    variable_pool=graph_engine.graph_runtime_state.variable_pool,
                    outputs=outputs,
                    graph_engine=graph_engine,
                )
                
                # 更新统计
                iter_run_map[str(index)] = (
                    datetime.now(UTC).replace(tzinfo=None) - iter_start_at
                ).total_seconds()
                
                self.graph_runtime_state.total_tokens += \
                    graph_engine.graph_runtime_state.total_tokens
                usage_accumulator[0] = self._merge_usage(
                    usage_accumulator[0],
                    graph_engine.graph_runtime_state.llm_usage,
                )
    
    def _execute_parallel_iterations(
        self,
        iterator_list_value: Sequence[object],
        outputs: list[object],
        iter_run_map: dict[str, float],
        usage_accumulator: list[LLMUsage],
    ) -> Generator[NodeEventBase, None, None]:
        """并行执行迭代"""
        
        # 初始化输出列表（占位）
        outputs.extend([None] * len(iterator_list_value))
        
        # 创建线程池
        with ThreadPoolExecutor(max_workers=self._node_data.parallel_nums) as executor:
            # 提交所有迭代任务
            futures = {}
            
            for index, item in enumerate(iterator_list_value):
                # 创建子图引擎
                graph_engine = self._create_graph_engine(index, item)
                
                # 提交任务
                future = executor.submit(
                    self._run_single_iter_in_thread,
                    variable_pool=graph_engine.graph_runtime_state.variable_pool,
                    graph_engine=graph_engine,
                    index=index,
                )
                futures[future] = index
            
            # 等待所有任务完成
            for future in as_completed(futures):
                index = futures[future]
                
                try:
                    # 获取结果
                    result = future.result()
                    
                    # 更新输出
                    outputs[index] = result
                    
                    # 发射迭代完成事件
                    yield IterationNextEvent(index=index)
                
                except Exception as e:
                    logger.exception("Iteration %s failed: %s", index, e)
                    
                    if self._node_data.error_handle_mode == ErrorHandleMode.TERMINATED:
                        raise
                    else:
                        # 继续执行模式：记录错误
                        outputs[index] = {"error": str(e)}
```

**并行 vs 串行**：

| 模式 | 优点 | 缺点 | 适用场景 |
|------|------|------|---------|
| **串行** | 顺序执行、易调试 | 慢 | 有依赖关系的迭代 |
| **并行** | 快速执行 | 资源消耗大、调试难 | 独立的迭代 |

```python
class LoopNode(Node):
    node_type = NodeType.LOOP
    execution_type = NodeExecutionType.CONTAINER
    
    def _run(self) -> Generator[NodeEventBase, None, None]:
        """执行循环节点"""
        
        # 1. 获取配置
        loop_count = self._node_data.loop_count
        break_conditions = self._node_data.break_conditions
        
        # 2. 初始化循环变量
        if self._node_data.loop_variables:
            for loop_variable in self._node_data.loop_variables:
                variable_selector = [self._node_id, loop_variable.label]
                self.graph_runtime_state.variable_pool.add(
                    variable_selector,
                    loop_variable.value,
                )
        
        # 3. 发射启动事件
        yield LoopStartedEvent(
            start_at=naive_utc_now(),
            metadata={"loop_length": loop_count},
        )
        
        # 4. 循环执行
        loop_duration_map: dict[str, float] = {}
        loop_usage = LLMUsage.empty_usage()
        
        for i in range(loop_count):
            # 检查中断条件
            if break_conditions:
                reach_break_condition = self._check_break_conditions(break_conditions)
                
                if reach_break_condition:
                    break
            
            # 创建子图引擎
            graph_engine = self._create_graph_engine(
                start_at=naive_utc_now(),
                root_node_id=self._node_data.start_node_id,
            )
            
            # 执行单次循环
            loop_start_time = naive_utc_now()
            reach_break_node = yield from self._run_single_loop(
                graph_engine=graph_engine,
                current_index=i,
            )
            
            # 记录时长
            loop_duration_map[str(i)] = (
                naive_utc_now() - loop_start_time
            ).total_seconds()
            
            # 累计 Token
            loop_usage = self._merge_usage(
                loop_usage,
                graph_engine.graph_runtime_state.llm_usage,
            )
            
            # 检查是否遇到 Break 节点
            if reach_break_node:
                break
        
        # 5. 发射成功事件
        yield LoopSucceededEvent(
            outputs={
                "iterations": i + 1,
            },
            metadata={
                "loop_duration_map": loop_duration_map,
            },
        )
```

**Break 节点**：

Loop 节点支持在子图中放置 Break 节点来中断循环。

```python
def _run_single_loop(
    self,
    graph_engine: GraphEngine,
    current_index: int,
) -> Generator[NodeEventBase, None, None]:
    """运行单次循环"""
    
    reach_break_node = False
    
    # 运行子图
    for event in graph_engine.run():
        # 检测 Break 节点
        if isinstance(event, NodeRunSucceededEvent):
            node = graph_engine._graph.nodes.get(event.node_id)
            if node and node.node_type == NodeType.LOOP_BREAK:
                reach_break_node = True
        
        # 转发事件
        yield event
    
    return reach_break_node
```

## 总结

Dify 工作流节点系统具有以下特点：

### 1. 统一的节点基类

所有节点继承自 `Node` 基类，提供统一的：
- 生命周期管理（初始化、执行、事件发射）
- 错误处理和重试
- 变量池访问
- 事件流式输出

### 2. 丰富的节点类型

| 类别 | 节点 | 核心能力 |
|------|------|---------|
| **AI 模型** | LLM, Agent | 流式输出、Memory、结构化输出 |
| **数据处理** | Code, HTTP Request | 沙箱执行、SSRF 防护 |
| **知识库** | Knowledge Retrieval | 多数据集检索、Rerank、元数据过滤 |
| **流程控制** | IF-ELSE | 多条件组合、逻辑运算 |
| **工具调用** | Tool | 内置/API/插件工具、参数转换 |
| **循环迭代** | Iteration, Loop | 串行/并行、条件中断 |

### 3. 灵活的输出模式

- **阻塞模式**：适合简单节点（Code, IF-ELSE）
- **流式模式**：适合长时间运行节点（LLM, Agent, Tool）

### 4. 强大的容器节点

- **Iteration**：遍历列表，支持并行执行
- **Loop**：循环执行，支持条件中断
- **嵌套子图**：容器节点内部运行独立的 GraphEngine

### 5. 安全性保障

- **Code 节点**：沙箱执行、资源限制
- **HTTP 节点**：SSRF 防护、超时控制
- **参数验证**：Pydantic 模型验证

这种设计使得 Dify 能够支持复杂的 AI 工作流场景，同时保持良好的可扩展性和安全性。
